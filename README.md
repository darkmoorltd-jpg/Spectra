# SPECTRA – Mineral Identification AI

SPECTRA is a Streamlit-based app that helps artisanal miners identify minerals, estimate ore grade, and get current market value.

## Features
- Upload a photo of a rock/ore sample.
- AI identifies the mineral (demo for now, real model later).
- Shows estimated grade and market value.
- (Future) Supabase authentication, scan history, payments.

## Setup
1. Clone this repo.
2. Install dependencies: `pip install -r requirements.txt`
3. Create `.streamlit/secrets.toml` from the example and add your keys.
4. Run: `streamlit run app.py`
